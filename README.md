# 🌾 O Protocolo Biosfera: Agrinho 2026 🌾

Projeto desenvolvido para o concurso Agrinho.

O Protocolo Biosfera é um jogo interativo em formato de narrativa de escolhas, no qual o jogador assume a missão de encontrar e executar um protocolo capaz de conciliar alta produtividade agrícola com a preservação ambiental. Ao longo da aventura, o usuário toma decisões relacionadas ao manejo do solo, controle biológico de pragas, integração lavoura-pecuária-floresta e uso eficiente da água, descobrindo na prática os impactos de cada escolha para o futuro da agricultura.

---

## Objetivo do projeto:

O objetivo do projeto é demonstrar, de forma educativa e interativa, como a ciência e as tecnologias sustentáveis podem tornar a produção agropecuária mais eficiente sem comprometer os recursos naturais. Através de uma narrativa gamificada, o projeto busca conscientizar sobre a importância da conservação do solo, da biodiversidade, dos recursos hídricos e das práticas agrícolas sustentáveis para garantir a segurança alimentar das futuras gerações.

---

## Tecnologias Utilizadas:

* **Estrutura:** HTML
* **Estilização:** CSS

* **Interatividade:** JavaScript

---

A agricultura e a preservação ambiental não precisam estar em lados opostos. Com planejamento, pesquisa científica e inovação tecnológica, é possível produzir mais alimentos, reduzir impactos ambientais e construir um futuro sustentável para todos.

Projeto criado para o Concurso Agrinho 2026, valorizando a educação, a sustentabilidade e o papel do agro no desenvolvimento da sociedade.
